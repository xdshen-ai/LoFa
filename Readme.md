# Truth or Sophistry? LoFa: A Benchmark for LLM Robustness Against Logical Fallacies

🚀 **Accepted at ACL 2026 (Main Conference)**

---

## 📖 Overview

**LoFa** (Logical Fallacy Benchmark) is a benchmark designed to evaluate the robustness of Large Language Models (LLMs) against logical fallacies.  
It aims to systematically assess whether models can correctly identify, resist, or are misled by flawed reasoning patterns.
